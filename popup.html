🌍 申請區域 (Select Region)
1️⃣ 輸入 API Key
📋 如何取得 API Key？
步驟 1：建立 Azure 帳號
前往 Microsoft Azure 入口
點擊「建立免費帳戶」，完成註冊（需要信用卡驗證，但不會扣款）
步驟 2：建立 Translator 資源
1. 點擊 「+ 建立資源」
2. 搜尋並選擇「Translator」
3. 點擊「建立」
步驟 3：設定資源
• 資源群組：建立新的 (名稱隨意)
• 區域：東亞 (East Asia) ⚠️ 重要
• 定價層：Free ✅
• 名稱：隨意 (如「MyVideoTranslator」)
步驟 4：複製 API Key
1. 資源建立完成後，進入資源
2. 左邊菜單 → 「Keys and Endpoint」
3. 複製 Key 1 或 Key 2
4. 貼到上面的輸入框，點「儲存」
