Microsoft Translator

🌍 申請區域
1️⃣ API Key
📋 如何取得 API Key?
步驟 1：建立 Azure 帳號
前往 Microsoft Azure
點擊「建立免費帳戶」，完成註冊
步驟 2：建立 Translator 資源
1. 點擊 「+ 建立資源」
2. 搜尋「Translator」
3. 點擊「建立」
步驟 3：設定資源
• 資源群組：建立新的
• 區域：東亞 ⚠️
• 定價層：Free ✅
步驟 4：複製 API Key
1. 進入資源
2. 左邊菜單 → 「Keys」
3. 複製 Key 1
4. 貼到上面，點「儲存」
💡 免費額度
每月 200 萬字 = 100+ 部電影字幕
